# Gilbert Erik Garcia — GitHub Pages

The homepage is `index.html`, a lightweight static page styled to match the GitHub Universe badge profile. It uses no external fonts, scripts, trackers, or build tools.

## Edit the page

- Change the headline and copy in `index.html`.
- `assets/gilberterik_profile_160.jpg` is the same portrait JPEG used by the badge app.
- `assets/texas-outline.svg` is the matching Texas silhouette used as the page mark and favicon.
- `assets/erik-garcia.vcf` is the vCard contact card generated with contact details, work email (`erik.garcia@ercot.com`), and embedded photo.
- Keep the displayed link aligned with the badge app's `PROFILE_URL` and `PROFILE_DOMAIN` settings.
